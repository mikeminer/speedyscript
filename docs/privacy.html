INFORMAZIONI SUL SITO

Privacy e contatti.

SpeedyScript è un sito statico ospitato su GitHub Pages. Non include un sistema di account proprio, moduli con invio a un server SpeedyScript, strumenti di analisi del traffico o cookie aggiunti dal sito. Anche il carattere tipografico è ospitato insieme alla pagina.

Il brief resta sotto il tuo controllo

Il modulo prepara il testo della richiesta nel tuo browser. Compilarlo o premere «Prepara la mia richiesta» non pubblica una discussione e non invia il testo a SpeedyScript. La pagina non salva il brief: ricaricandola potresti perderlo.

«Copia il brief» usa gli appunti del tuo dispositivo, se disponibili. Con «Apri Discussions» lasci il sito e apri una bozza di discussione: il titolo e, quando la lunghezza lo permette, il testo vengono inseriti nell’indirizzo del collegamento e quindi trasmessi a GitHub. Puoi rivederli prima di pubblicare. Se il testo non è importato, puoi incollare la copia del brief.

Le richieste su Discussions sono pubbliche

Serve un account GitHub per pubblicare. Una volta pubblicati, richiesta, risposte ed eventuali allegati sono visibili nel repository pubblico. Non inserire password, token, chiavi API, dati di clienti, file riservati o informazioni personali che non vuoi rendere pubbliche.

Per chiedere una modifica o la rimozione di contenuti che hai pubblicato, usa le funzioni GitHub disponibili per i tuoi messaggi o contatta il gestore attraverso le discussioni del progetto, senza aggiungere altri dati riservati.

Hosting e servizi esterni

GitHub gestisce l’hosting e il forum secondo le proprie condizioni, compreso il trattamento dei dati tecnici delle richieste e degli account. Puoi leggere la privacy policy di GitHub. Le funzioni del forum, l’autenticazione e la conservazione dei messaggi dipendono da quel servizio.
